# История изменений

[English](CHANGELOG.md) · **Русский**

Версия задаётся в одном месте — `ChestReachPlugin.Version` в `src/ChestReachPlugin.cs`.

## 0.1.0

- Первая версия. Крафт и улучшение из сундуков вокруг станции, стройка из сундуков вокруг вас,
  станции (топливо, руда, еда, основы медовухи, топливо щита, снаряды баллисты) с одним
  предметом из сундука; «починить всё»; починка построек вокруг по `;`.
- Только клиент: из сундука берётся после того, как владелец отдал его через ванильный
  запрос открытия, на который отвечает и игрок без мода. Ничего нового по сети, ничего не
  хранится вне мира. Настройки хоста действуют на всех с модом.
- Сундуки индексируются один раз и пересчитываются только при изменении: меню крафта и
  стройки не тормозят рядом с большим складом.
